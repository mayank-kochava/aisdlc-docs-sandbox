## Implementation Guide

1. Open Aim.DataIngestion.DataSuppliers/KochavaRedshift/KochavaRedshiftReport.cs and locate Validate().
2. Add a check that throws InvalidOperationException("KochavaRedshift: CohortPeriods must not be empty.") when CohortPeriods.Count == 0.
3. Add a check that throws InvalidOperationException("KochavaRedshift: LookbackWeeks must be greater than zero.") when LookbackWeeks <= 0.
4. Add a check over AppAssociations that throws InvalidOperationException("KochavaRedshift: Duplicate KochavaId detected: {value}") for the first duplicated KochavaId.
5. Keep the existing missing-field checks, and read data-model.md for background only without editing it.
6. Add Validate_* cases for the three new checks in KochavaRedshiftReportTests.cs.

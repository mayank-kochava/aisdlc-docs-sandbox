## Implementation Guide

1. Open IngestionTaskFactory.cs and add using Aim.DataIngestion.Core.DataConsolidation.Services.KochavaRedshift;.
2. In the dataconsolidation case Aggregators block, add builder.RegisterType<KochavaRedshiftDataAggregator>().AsSelf().InstancePerDependency();.
3. In the Consolidators block, add builder.RegisterType<KochavaRedshiftDataConsolidator>().AsSelf().InstancePerDependency();.
4. Leave the existing dataimport.kochavaredshift case unchanged.
5. Write IngestionTaskFactoryKochavaRedshiftTests.cs that builds the dataconsolidation container and resolves both types.

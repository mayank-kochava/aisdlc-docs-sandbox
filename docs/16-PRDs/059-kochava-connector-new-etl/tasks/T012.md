## Acceptance Criteria

- WHEN the Kochava Redshift config is not found THE SYSTEM SHALL log a fatal error and throw. [FR-001]
- WHEN credential resolution fails THE SYSTEM SHALL log a fatal error and throw. [FR-003]
- WHEN a date window returns zero rows THE SYSTEM SHALL skip the bulk copy for that window and continue with the next one. [BR-09]
- WHEN all date windows succeed THE SYSTEM SHALL call RemoveDuplicatesAsync, MergeTablesAsync and ReplaceDataAndMergeTablesAsync in that order. [BR-09]
- WHEN the report query throws THE SYSTEM SHALL log the task failure and rethrow the exception. [BR-09]
- Existing tests pass
- New functionality has test coverage
- Code follows repository conventions (see CLAUDE.md)

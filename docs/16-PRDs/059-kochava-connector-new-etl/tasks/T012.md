## Implementation Guide

1. Read Aim.DataIngestion.Tests/Core/DataImport/Services/BigQuery/BigQueryDataImportServiceTests.cs and copy its mock setup (logger, config service, data service, report).
2. Create Aim.DataIngestion.Tests/Core/DataImport/Services/KochavaRedshift/KochavaRedshiftDataImportServiceTests.cs targeting KochavaRedshiftDataImportService.
3. Add DownloadReportAsync_ConfigNotFound_LogsFatalAndThrows and DownloadReportAsync_CredentialResolutionFails_LogsFatalAndThrows. Assert IApplicationLogger.Fatal is called and the exception propagates.
4. Add DownloadReportAsync_ZeroRowsForWindow_SkipsBulkCopyAndContinues. A window returning zero rows must not trigger BulkS3Copy and the next window must still be processed.
5. Add DownloadReportAsync_HappyPath_CallsMergeStepsInCorrectOrder. Verify the order RemoveDuplicates, then MergeTables, then ReplaceDataAndMergeTables.
6. Add DownloadReportAsync_QueryThrows_LogsFailureAndRethrows. Assert the failure is logged and the exception is rethrown.

## Acceptance Criteria

- WHEN the config is not found THE SYSTEM SHALL log Fatal and throw. [Flow A]
- WHEN credential resolution fails THE SYSTEM SHALL log Fatal and throw. [Flow A]
- WHEN a date window returns zero rows THE SYSTEM SHALL skip BulkS3Copy for that window and continue with the next. [Flow A]
- WHEN all windows succeed THE SYSTEM SHALL call RemoveDuplicates, then MergeTables, then ReplaceDataAndMergeTables, in that order. [BR-09]
- WHEN the report query throws THE SYSTEM SHALL log the task failure and rethrow the exception. [Flow A]
- Existing tests pass
- New functionality has test coverage
- Code follows repository conventions (see CLAUDE.md)

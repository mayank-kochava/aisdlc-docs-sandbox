## Implementation Guide

1. Before starting, confirm these are in place in dev: the MongoDB config and its configId (T013), the secret (T014), network reachability (T015), and a build containing the import service and report code (T006, T007). These are preconditions only and are not declared dependencies.
2. Before the run, have the Sharawmer owner give a lower and upper bound for the expected `_main` row count, and record both on the ticket.
3. Run the `dataimport.kochavaredshift` task with the Sharawmer configId against the dev Kochava Redshift.
4. Check the task logs for success, row counts and elapsed time, with no config, credential or fatal error.
5. Query `kochavaredshift_costandattribution_{configId}_main`: COUNT(*) against the recorded bounds, `SELECT DISTINCT country`, and a COUNT of rows whose app_id is not among the configured AppAssociations AppId values.

## Implementation Guide

1. Confirm T013 (config) and T015 (network path and credentials) are complete.
2. Run the dataimport.kochavaredshift task for Sharawmer with its configId on dev.
3. Check the logs for row counts, elapsed time and the absence of fatal errors, including the AppAssociation config error raised when 100% of rows are dropped.
4. Query the feature store _main table and confirm the row count is greater than zero.
5. Confirm every app_id in _main appears in the configured AppAssociations.
6. Record the row count and results on the task.

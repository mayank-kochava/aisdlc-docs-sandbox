## Implementation Guide

1. Create Aim.DataIngestion.Tests/DataSuppliers/KochavaRedshift/KochavaRedshiftReportTests.cs, following the BaseBigQueryReportValidateTests pattern.
2. Add a helper that builds a fully valid config for KochavaRedshiftReport (server, database name, schema, table, credentials, cohort periods, lookback weeks, app associations).
3. Add Validate_MissingServer_Throws, Validate_MissingDatabaseName_Throws, Validate_MissingSchema_Throws, Validate_MissingTable_Throws and Validate_MissingCredentials_Throws. Each starts from the valid config and removes exactly one field.
4. Add Validate_EmptyCohortPeriods_Throws, Validate_ZeroLookbackWeeks_Throws, Validate_DuplicateKochavaId_Throws and Validate_EmptyAppAssociations_Throws using the same one-defect-at-a-time approach.
5. In every test, assert that Validate() throws InvalidOperationException. Also confirm the valid baseline config does not throw, so a failure can only come from the removed field.

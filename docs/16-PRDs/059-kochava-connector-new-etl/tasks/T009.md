## Implementation Guide

1. Open the existing BaseBigQueryReportValidateTests in Aim.DataIngestion.Tests as the pattern reference.
2. Create Aim.DataIngestion.Tests/DataSuppliers/KochavaRedshift/KochavaRedshiftReportTests.cs (xUnit).
3. Add a helper that builds a fully valid KochavaRedshiftReport and config, so each test can blank out one field.
4. Add Validate_MissingServer_Throws, Validate_MissingDatabaseName_Throws, Validate_MissingSchema_Throws and Validate_MissingTable_Throws.
5. Add Validate_MissingCredentials_Throws, Validate_EmptyCohortPeriods_Throws, Validate_ZeroLookbackWeeks_Throws, Validate_DuplicateKochavaId_Throws and Validate_EmptyAppAssociations_Throws.
6. Assert InvalidOperationException in every test, and confirm a fully valid config does not throw.

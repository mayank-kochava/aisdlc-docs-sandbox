## Acceptance Criteria

- WHEN SwapKochavaAppIds receives a non-empty record list and no record matches an AppAssociation THE SYSTEM SHALL throw InvalidOperationException with a message starting "KochavaRedshift: 0 of {N} records matched any configured AppAssociation". [FR-014b]
- WHEN SwapKochavaAppIds receives an empty record list THE SYSTEM SHALL return without throwing. [FR-014b]
- WHEN at least one record matches an AppAssociation THE SYSTEM SHALL replace the KochavaId with the associated AppId and drop unmatched rows. [BR-02]
- WHEN every row in a window is dropped for AppAssociation mismatch THE SYSTEM SHALL treat the run as a fatal config error. [BR-11]
- Existing tests pass
- New functionality has test coverage
- Code follows repository conventions (see CLAUDE.md)

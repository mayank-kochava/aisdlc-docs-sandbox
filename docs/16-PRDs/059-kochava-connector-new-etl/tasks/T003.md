## Implementation Guide

1. Create the static class KochavaRedshiftQueryBuilder in Aim.DataIngestion.DataSuppliers/KochavaRedshift/KochavaRedshiftQueryBuilder.cs.
2. Implement BuildQuery(KochavaRedshiftConfigModel config, DateTime startDate, DateTime endDate), selecting from the Kochava source table with appid IN (KochavaIds) and the date window.
3. Build the country-code CASE from config.CountryCodes using the ~* regex (^|[ _\-\.])<code>($|[ _\-\.]) (BR-13).
4. Add GROUP BY on the aliased countrycode and HAVING countrycode IS NOT NULL.
5. Generate the cohort-period pivot columns from config.CohortPeriods.
6. Write KochavaRedshiftQueryBuilderTests.cs for a single country code (['sa']), multiple codes and multiple cohort periods.

## Acceptance Criteria

- WHEN BuildQuery is called with CountryCodes ['sa'] THE SYSTEM SHALL emit SQL containing ~* and the pattern (^|[ _\-\.])sa($|[ _\-\.]). [FR-010]
- WHEN BuildQuery is called THE SYSTEM SHALL emit a CASE that yields a countrycode alias, with GROUP BY on that alias and HAVING countrycode IS NOT NULL. [FR-011]
- WHEN BuildQuery is called with several CohortPeriods THE SYSTEM SHALL emit a pivot column for every period. [FR-012]
- WHEN BuildQuery is called THE SYSTEM SHALL restrict rows to the startDate-endDate window and appid IN (KochavaIds). [FR-010]

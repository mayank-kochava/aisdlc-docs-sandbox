## Implementation Guide

1. Create KochavaRedshiftDataConsolidator in KochavaRedshiftDataConsolidator.cs with primary constructor (ISchemaService schemaService, IDataConsolidationSql dataConsolidationSql), inheriting BaseDataConsolidator.
2. Implement Consolidate(DataSupplierRules, List<string>, string, IDataService, DataConsolidationCommonConfig).
3. Resolve the dataset type with DatasetContextResolver.GetConsolidationDatasetType(DatasetType.CostAndAttribution).
4. Get table definitions from KochavaRedshiftFeatureStoreTableDefinitions and call Merge(rules, regions, featureStoreDataService, tDef.AggregateTable.TableName, networksToJoinOnCampaignId: ...).
5. Write KochavaRedshiftDataConsolidatorTests.cs verifying the Merge call uses the aggregate table name and the CostAndAttribution dataset type.

## Implementation Guide

1. Read Aim.DataIngestion.Core/DataConsolidation/Services/BigQuery/BigQueryDataConsolidator.cs as the exemplar.
2. Create Aim.DataIngestion.Core/DataConsolidation/Services/KochavaRedshift/KochavaRedshiftDataConsolidator.cs extending BaseDataConsolidator, with constructor (ISchemaService schemaService, IDataConsolidationSql dataConsolidationSql) : base(dataConsolidationSql).
3. Get tDef from KochavaRedshiftFeatureStoreTableDefinitions.GetTableDefinitions(schema, schemaService, DatasetContextResolver.GetConsolidationDatasetType(DatasetType.CostAndAttribution), rules.DataSupplierConfigId).
4. Call Merge(rules, regions, featureStoreDataService, tDef.AggregateTable.TableName, networksToJoinOnCampaignId: consolidationCommonConfig.NetworksToJoinOnCampaignId).
5. Mirror the BigQuery version's structure, and build the solution.

2. Check that the generated SQL uses the ~* pattern (^|[ _\-\.])sa($|[ _\-\.]) for CountryCodes = ["sa"].
3. Redshift allows output-column aliases in GROUP BY, so confirm this against dev Redshift or the Redshift docs.
4. Record the finding as a code comment above the GROUP BY clause in BuildQuery.
5. Add a test in KochavaRedshiftReportBuildQueryTests.cs asserting the SQL contains ~*, the CASE, the GROUP BY on the alias and HAVING countrycode IS NOT NULL.

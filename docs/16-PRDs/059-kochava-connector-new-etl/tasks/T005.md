**Fields:**

| Rule | Error |

| `CohortPeriods.Count > 0` | `"KochavaRedshift: CohortPeriods must not be empty."` |

## Implementation Guide

1. Create the static class KochavaRedshiftAppIdMapper in KochavaRedshiftAppIdMapper.cs.
2. Implement SwapKochavaAppIds(List<KochavaRedshiftReportModel> records, IReadOnlyList<AppAssociation> associations), replacing each record's KochavaId with the matching AppId in memory.
3. Remove records that have no matching association (defensive guard even though SQL pre-filters).
4. If records is non-empty and every record is unmatched, throw an exception that names an AppAssociation configuration error (BR-11).
5. Write KochavaRedshiftAppIdMapperTests.cs for a match, a partial match, a 100% mismatch and an empty list.

## Acceptance Criteria

- WHEN a record's KochavaId matches an association THE SYSTEM SHALL replace it with that association's AppId. [FR-013]
- WHEN only some records are unmatched THE SYSTEM SHALL drop the unmatched records and keep the matched ones. [FR-014]
- WHEN 100% of a non-empty record list is unmatched THE SYSTEM SHALL throw an error identifying an AppAssociation configuration problem. [FR-014b]
- WHEN the record list is empty THE SYSTEM SHALL return without throwing. [FR-014b]

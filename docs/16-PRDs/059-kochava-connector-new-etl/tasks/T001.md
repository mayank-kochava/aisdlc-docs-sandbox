## Spec Excerpts

### KochavaRedshiftConfigModel

**Purpose:** MongoDB document driving a single `dataimport.kochavaredshift` task run. Deserialized from `data_supplier_configs` collection.

**Fields:**

| Field | Type | Required | Description |
| :--- | :--- | :---: | :--- |
| `DataSupplierConfigId` | string | Yes | Unique document ID; passed as task argument |
| `AdvertiserId` | string | Yes | Internal advertiser ID |
| `AdvertiserName` | string | Yes | Used to locate AWS Secrets Manager secret |
| `ConnectorType` | string | Yes | Must equal `"KochavaRedshift"` |
| `DatasetType` | enum | Yes | e.g., `CostAndAttribution` |
| `ConnectorCredential.UsernameSecretKey` | string | Yes | Field name in AWS secret; default `"KochavaRedshiftUsername"` |
| `ConnectorCredential.PasswordSecretKey` | string | Yes | Field name in AWS secret; default `"KochavaRedshiftPassword"` |
| `ConnectorCredential.ResolvedUsername` | string | Runtime | Populated at runtime from Secrets Manager; `[JsonIgnore]` |
| `ConnectorCredential.ResolvedPassword` | string | Runtime | Populated at runtime from Secrets Manager; `[JsonIgnore]` |
| `AdvertiserConfig.Server` | string | Yes | Kochava RS hostname |
| `AdvertiserConfig.Port` | int | Yes | Default: `5439` |
| `AdvertiserConfig.DatabaseName` | string | Yes | Kochava RS database |
| `AdvertiserConfig.Schema` | string | Yes | Kochava RS schema |
| `AdvertiserConfig.Table` | string | Yes | Kochava RS source table |
| `AdvertiserConfig.AppAssociations` | `List<KochavaAppAssociation>` | Yes | At least one entry; no duplicate KochavaIds |
| `AdvertiserConfig.CountryCodes` | `List<string>` | Yes | ISO codes; e.g., `["sa"]` |
| `AdvertiserConfig.CohortPeriods` | `List<string>` | Yes | Non-empty; e.g., `["1","7","30","90"]` |
| `AdvertiserConfig.CohortMetricEventMappings` | `Dictionary<string,List<string>>` | Yes | Metric name → source column(s) |
| `AdvertiserConfig.LookbackWeeks` | int | Yes | Must be > 0 |
| `AdvertiserConfig.WeeklyGrouping` | bool | Yes | `false` = daily windows; `true` = weekly |

**Validation Rules:**

| Rule | Error |
| :--- | :--- |
| `LookbackWeeks > 0` | `"KochavaRedshift: LookbackWeeks must be greater than zero."` |
| `CohortPeriods.Count > 0` | `"KochavaRedshift: CohortPeriods must not be empty."` |
| `AppAssociations.Count > 0` | `"KochavaRedshift: At least one AppAssociation is required."` |
| No duplicate `KochavaId` in `AppAssociations` | `"KochavaRedshift: Duplicate KochavaId detected: {value}"` |
| `Server`, `DatabaseName`, `Schema`, `Table` non-empty | Per-field error messages in `Validate()` |
| `ResolvedUsername` + `ResolvedPassword` non-empty (after secret resolution) | `"KochavaRedshift: Credentials not resolved."` |

namespace Aim.DataIngestion.Core.Shared.Services;

public delegate IEnumerable<TReport> FunctionPipelineStep<TReport, TConfig>(IEnumerable<TReport> dataSet, TConfig dsConfig, IApplicationLogger logger);

public class FunctionPipeline<TReport, TConfig>
{
    private readonly List<FunctionPipelineStep<TReport, TConfig>> _steps = [];

    public FunctionPipeline<TReport, TConfig> AddFunction(FunctionPipelineStep<TReport, TConfig> step)
    {
        _steps.Add(step);
        return this;
    }

    public IEnumerable<TReport> Execute(IEnumerable<TReport> dataSet, TConfig dsConfig, IApplicationLogger logger)
    {
        var resultSet = dataSet;
        foreach (var step in _steps)
        {
            resultSet = step(resultSet, dsConfig, logger);
        }
        return resultSet;
    }
}

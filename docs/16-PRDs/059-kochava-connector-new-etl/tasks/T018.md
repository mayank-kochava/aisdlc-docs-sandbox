## Implementation Guide

1. Confirm T017 passed: the Sharawmer aggregate table on dev has rows, per the T017 task notes.
2. Before the run, list the existing views in the dev feature store (for example `SELECT viewname FROM pg_views;`) and save the output as a baseline.
3. Trigger the `featurecreation` task for the Sharawmer configId on dev and capture the ETL pod log. Search it for `Fatal` or `LogTaskFailure` entries.
4. Re-run the view listing. Diff it against the baseline and confirm the new views include a South Africa holiday view and a day-of-week view. Record their names.
5. Trigger `featurecreation.postprocessor` for the Sharawmer configId on dev and capture its pod log. Search it for `Fatal` or `LogTaskFailure` entries.
6. Run `SELECT table_name FROM information_schema.columns WHERE column_name = 'data_smoothing_index';` and confirm it returns at least one Sharawmer feature table. Record the results in the task notes.

## Implementation Guide

1. Build the Sharawmer DataSupplierConfig document so its fields match the existing KochavaRedshiftConfigModel.cs (ConnectorType, CountryCodes, LookbackWeeks, CohortPeriods, CohortMetricEventMappings, AppAssociations, UsernameSecretKey, PasswordSecretKey).
2. Set ConnectorType to "KochavaRedshift" and CountryCodes to ["sa"]. Fill LookbackWeeks, CohortPeriods, CohortMetricEventMappings and AppAssociations with the correct Sharawmer KochavaId values, with no duplicate KochavaIds.
3. Set UsernameSecretKey to "KochavaRedshiftUsername" and PasswordSecretKey to "KochavaRedshiftPassword". These are the field names the eng-plan prescribes for the advertiser secret, so this step does not depend on T014's output.
4. Insert the document into the MongoDB data_supplier_configs collection on dev with mongosh insertOne, and record the resulting configId.
5. Confirm the document loads through IMetadataConfigService.GetKochavaRedshiftConfigAsync using that configId.

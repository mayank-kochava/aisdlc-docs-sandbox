## Implementation Guide

1. Get the Kochava Redshift hostname from ops. It is the same value that goes in the Server field of the Sharawmer config in T013. Take it from the ops ticket, not from MongoDB.
2. Open a shell inside an ETL Kubernetes pod in the dev environment.
3. Run `nc -zv {kochava-rs-host} 5439` with that hostname.
4. Record the result (success or failure) on the ticket.
5. If the host is unreachable, escalate to infra and stop. Do not start T016 until connectivity is confirmed.
6. Do not set up an SSH tunnel as a workaround, since only direct connections are supported.

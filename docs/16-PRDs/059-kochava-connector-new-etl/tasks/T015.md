## Implementation Guide

1. Get the Kochava Redshift host and port for dev from ops. Do not read them from the Sharawmer config, which this task does not depend on.
2. From a dev ETL pod, test a direct TCP connection to that host and port.
3. If the connection is blocked, raise the firewall or VPC change with ops, then re-test.
4. Using the T014 credentials, confirm the pod can open a connection and authenticate against Kochava Redshift.
5. Record the host, port and result on the task.

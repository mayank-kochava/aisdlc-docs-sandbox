## Implementation Guide

1. Create Aim.DataIngestion.Tests/DataSuppliers/KochavaRedshift/KochavaRedshiftReportBuildQueryTests.cs (xUnit).
2. Build a KochavaRedshiftReport with CountryCodes = ["sa"] and call BuildQuery().
3. Write BuildQuery_SingleCountryCode_ContainsRegexAndCasePattern: assert the SQL contains `~*`, the pattern `(^|[ _\-\.])sa($|[ _\-\.])`, a country-code CASE expression and a HAVING clause filtering NULL country code.
4. Write BuildQuery_MultipleCohortPeriods_GeneratesAllColumnAliases: configure several CohortPeriods with CohortMetricEventMappings and assert a column alias exists for each period.
5. Assert the SQL selects the daus, clicks and impressions columns, as the plan confirms.

## Implementation Guide

1. Create Aim.DataIngestion.Tests/DataSuppliers/KochavaRedshift/KochavaRedshiftReportBuildQueryTests.cs.
2. Before building any test config, open KochavaRedshiftConfigModel.cs and KochavaRedshiftReport.cs. Read the real shape of CountryCodes, CohortPeriods and CohortMetricEventMappings, and how BuildQuery() names its aliases. Use those types as they are and do not invent properties.
3. Write BuildQuery_SingleCountryCode_ContainsRegexAndCasePattern. Use CountryCodes = ["sa"], call BuildQuery(), and assert the SQL contains `~*`, `(^|`, `countrycode` and `HAVING`.
4. Write BuildQuery_MultipleCohortPeriods_GeneratesAllColumnAliases. Use CohortPeriods = ["1","7","30","90"] and a CohortMetricEventMappings entry for `revenue`, expressed in the shape found in the config model.
5. In that test, assert the SQL contains exactly `revenue7d`, `revenue30d` and `revenue90d`. Do not assert aliases for other periods unless BuildQuery() visibly defines them and you can quote the literal string.

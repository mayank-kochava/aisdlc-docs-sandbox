## Implementation Guide

1. Read Aim.DataIngestion.Core/DataConsolidation/Services/BigQuery/BigQueryDataAggregator.cs as the exemplar.

3. Call KochavaRedshiftFeatureStoreTableDefinitions.GetTableDefinitions(schema, schemaService, datasetType, supplierRules.DataSupplierConfigId) to get tDef.
4. Call PrimeTablesByDropAsync([tDef.AggregateTable], [tDef.AggregateTable]).

6. Use primary-constructor syntax consistent with the codebase, and build the solution.

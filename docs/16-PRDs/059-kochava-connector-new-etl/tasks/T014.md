## Implementation Guide

1. Create the AWS Secrets Manager secret {env}/AIMETLService/Sharawmer, starting with dev, and repeat for each other environment.
2. Add the two fields the eng-plan names, KochavaRedshiftUsername and KochavaRedshiftPassword, inside this advertiser secret and not in a separate Redshift-specific secret.
3. Grant the ETL service's role read access to the secret.
4. List the secret's field names (keys only, never values) and confirm both fields exist and are non-empty.

## Implementation Guide

1. Create `ratelimit/example_test.go` (package `ratelimit_test`) with `func Example()`.
2. Build a fake clock with `NewFakeClock` and a limiter via `ratelimit.New(1, 2, clock)` (rate 1/s, burst 2).
3. Print the result of three consecutive `Allow()` calls with `fmt.Println`.
4. Call `clock.Advance(time.Second)`, then print one more `Allow()` result.
5. Add the `// Output:` block with exactly `true`, `true`, `false`, `true`, one per line.
6. Run the test command and confirm the example passes.

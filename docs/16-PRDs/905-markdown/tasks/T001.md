- **Design:** one struct holding `tokens float64`, `last time.Time` and a `sync.Mutex`. Each call refills `min(burst, tokens + elapsed*rate)`, then spends. Time comes through a `Clock` interface so tests use a fake clock and never sleep.

## Implementation Guide

1. Create `ratelimit/clock.go` in package `ratelimit` using only the standard library.
2. Define `type Clock interface{ Now() time.Time }`.
3. Implement `SystemClock() Clock` returning a clock whose `Now()` returns `time.Now()`.
4. Define `FakeClock` holding a `time.Time`, with `NewFakeClock(t time.Time) *FakeClock`, `Now()` and `Advance(d time.Duration)`.
5. Write `ratelimit/clock_test.go` covering `NewFakeClock` + `Now`, `Advance` (including multiple advances) and `SystemClock` returning a usable clock. Tests must never sleep.
6. Run `go vet ./...` and the test command, and confirm both pass.

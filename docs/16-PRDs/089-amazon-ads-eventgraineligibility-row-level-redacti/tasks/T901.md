## Implementation Guide

1. Create src/krepdetailworkerv13/rowlevel.go with the const rowLevelRestrictedKey = "row_level_restricted" and the map restrictedRulesCSV (network id to output column positions).
2. Implement rowHasRestrictionFlag(cells ...string) bool. It is true when any cell contains `"row_level_restricted":true`.
3. Implement applyRowLevelRestriction(rowArr, cols, requestCells...) bool. It masks the listed columns with "---" only when a cell is flagged, returns whether it masked, and ignores negative or out-of-range indexes.
4. Implement originalRequestCellsInRange(rowArr, reqCols, from, to) and loadRowLevelRules(mySQLPartner, colPos2Sanitize). The rules come from the report_filtering row for partner amazonadssan, using sanitizeRulesCSV and the cpi_networks mapping.
5. In main.go, call loadRowLevelRules at setup and applyRowLevelRestriction per row in the CSV sanitization path. Use the request cells from install_original_request / click_original_request / ad_information, and leave rows of other networks untouched.
6. Write rowlevel_test.go first (flagged row masked, unflagged unchanged, row count unchanged, bad indexes ignored). Run it locally; this worker has no CI, so paste the output in the PR.

## Acceptance Criteria

- WHEN a row's original-request cells contain "row_level_restricted":true THE SYSTEM SHALL replace the configured Amazon columns in that row with "---". [BR-2, BR-9]
- WHEN no cell of a row carries the flag THE SYSTEM SHALL leave the row byte-identical. [BR-2]
- WHEN a row is masked THE SYSTEM SHALL keep the row in the output and change only the configured columns. [BR-3]
- WHEN the row belongs to a network other than 13954 THE SYSTEM SHALL apply no row-level masking. [BR-1]
- WHEN a configured column index is negative or beyond the row length THE SYSTEM SHALL skip it without error. [BR-8]

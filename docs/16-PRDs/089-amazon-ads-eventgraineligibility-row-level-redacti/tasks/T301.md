## Implementation Guide

1. Add a failing test in `cmd/query/blacklist_test.go` for `unredacted_app_N` and `account_N_unredacted` table names.
2. Add the entry `"unredacted"` to `blacklistedDatasets` in `cmd/query/blacklist.go`.
3. Make sure the test also checks that ordinary `app_N` and `account_N` tables are still allowed.
4. Run the package tests.

## Acceptance Criteria

- WHEN a query targets a dataset named `unredacted_app_N` THE SYSTEM SHALL reject the request. [FR-050]
- WHEN a query targets a dataset named `account_N_unredacted` THE SYSTEM SHALL reject the request. [FR-051]
- WHEN a query targets a regular `app_N` or `account_N` dataset THE SYSTEM SHALL accept it as before. [NFR-006]
- WHEN table names are matched THE SYSTEM SHALL do so case-insensitively through the existing `strings.Contains` check. [NFR-007]
- Existing tests pass
- New functionality has test coverage
- Code follows repository conventions (see CLAUDE.md)

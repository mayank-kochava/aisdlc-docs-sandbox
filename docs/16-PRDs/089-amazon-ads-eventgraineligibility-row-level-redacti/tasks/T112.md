## Implementation Guide

1. Confirm T410 (unredacted_app_N synced for all apps), T502, T601, T701 and T801 are deployed to QA.
2. Run the rollup-worker-cloud unit tests for the query builders before deploying.
3. Run a rollup job on a QA app with NO active 13954 configuration row and record the output counts.
4. Compare the counts and breakdowns with the output of the previous build for the same app and date range.
5. Add a 13954 configuration row in QA, rerun the same job and compare again.
6. Record the comparison results in the PR.

## Acceptance Criteria

- WHEN a rollup job runs for an app with no active 13954 configuration row THE SYSTEM SHALL produce counts and breakdowns identical to the pre-change output. [BR-7]
- WHEN a rollup job runs with a 13954 configuration row present THE SYSTEM SHALL produce counts and breakdowns identical to those with no configuration row. [FR-031]
- WHEN the readers run in QA THE SYSTEM SHALL complete without a missing-table error on any `unredacted_app_N`. [NFR-013]
- WHEN the dry-run finishes THE SYSTEM SHALL show no difference in row counts between the old and new readers. [NFR-003]
- Existing tests pass
- New functionality has test coverage
- Code follows repository conventions (see CLAUDE.md)

## Implementation Guide

1. Create `cmd/rollup-worker-cloud/buildquery_test.go` with the helpers `testCfg`, `mustContain` and `mustNotContain`, and write failing tests first.
2. In `buildquery.go`, add `(c *Config) rawNetworksCTE()`: select from `<ReadProjectID>.network_sanitization.configuration` where `timeframe='day' AND active=true AND network_id='13954'`.
3. Add `(c *Config) src(j jobStruct, table, dateCol string) string`, returning a parenthesised UNION ALL subquery that reads 13954 rows inside the config window from `unredacted_app_N` and everything else from `app_N`.
4. Use `jobStruct.AppID` and `Config.ReadProjectID` to build the table names.
5. Change `buildQuerySUMMARY` to take `installs`, `events` and `san_claims` from `c.src(...)`, and prepend the CTE. Keep its signature.
6. Run the package tests.

**Consumes:**

```
`kochava-query-1370.network_sanitization.configuration` and `account_N_unredacted.analytics` (existing)
```

**Produces:**

```
Each listed dataset's `sql:` replaces its `account_{{ cache_key_wrapper(get_kochava_account_id()) }}.analytics` source (analytics.yaml:12; cost_measurement.yaml:31-32 and :50-51; aggregated_insights_match_to_type_filter.yaml:9; aggregated_insights_app_campaign_filter.yaml:8-12) with an inline subquery: `(WITH tmp_configuration AS (SELECT SAFE_CAST(network_id AS INT) AS network_id, SAFE_CAST(start_date AS TIMESTAMP) AS start_date, SAFE_CAST(end_date AS TIMESTAMP) AS end_date FROM `kochava-query-1370.network_sanitization.configuration` WHERE timeframe = 'day' AND active = true AND network_id = '13954') SELECT a.* FROM <account_N.analytics> a LEFT JOIN tmp_configuration c ON a.network_id = c.network_id AND a._date >= c.start_date AND a._date < COALESCE(c.end_date, '2099-12-31') WHERE c.network_id IS NULL UNION ALL SELECT a.* FROM <account_N_unredacted.analytics> a INNER JOIN tmp_configuration c ON a.network_id = c.network_id AND a._date >= c.start_date AND a._date < COALESCE(c.end_date, '2099-12-31'))` keeping each dataset's existing alias (`a` / `analytics`).
```

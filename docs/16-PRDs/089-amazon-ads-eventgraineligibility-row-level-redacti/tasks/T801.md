## Implementation Guide

1. In pkg/directmatch/getter.go, add the consts unredactedSource = "unredacted" and unredactedTable = "`%s.account_%d_unredacted.analytics`".
2. Add the appIDLookup interface with getAppIDFromAnalytics and getAppIDFromSKAD, matching the existing bqGetter signatures in bigquery.go:47,96.
3. Add resolveAppID(ctx, request MatchRequest, bq appIDLookup) (appID int64, source string, err error). It keeps the current lookup order but inserts the unredacted analytics step between the analytics step and the restricted step.
4. Switch the existing getter to call resolveAppID.
5. Write getter_test.go first, using a fake appIDLookup. Cover: analytics hit stops early; analytics miss leads to an unredacted hit with source "unredacted"; all misses fall through to restricted.
6. Run the package tests.

## Acceptance Criteria

- WHEN the analytics lookup finds no app and the unredacted lookup finds one THE SYSTEM SHALL return that app ID with source "unredacted". [BR-7]
- WHEN the analytics lookup finds an app THE SYSTEM SHALL return it without querying the unredacted table. [BR-7]
- WHEN both analytics and unredacted lookups find nothing THE SYSTEM SHALL continue to the restricted step as before. [BR-7]
- WHEN the unredacted table is queried THE SYSTEM SHALL use `<project>.account_<id>_unredacted.analytics`. [BR-7]

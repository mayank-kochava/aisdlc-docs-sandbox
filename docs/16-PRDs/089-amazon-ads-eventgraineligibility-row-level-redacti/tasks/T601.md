## Implementation Guide

1. In pkg/analyticstechspecs/namerproduction.go, add StandardSource(accountID int64) on productionAnalyticsNamer. It returns the parenthesised subquery: a tmp_configuration CTE (network_id='13954', timeframe='day', active=true), a LEFT JOIN on account_N.analytics keeping rows outside the config window, and a UNION ALL INNER JOIN on account_N_unredacted.analytics inside the window.
2. Use StandardSource at the two analytics source sites in namerproduction.go (around :92 and :353) in place of the bare account_N.analytics table.
3. In pkg/analyticstechspecs/namerconditional.go (around :42), route the bare-table path through the same source.
4. Write failing tests first in namerproduction_test.go and namerconditional_test.go. Cover the generated SQL (CTE, window predicate, UNION ALL) and confirm non-13954 networks fall on the redacted side.
5. Run the package tests and fix gaps until they pass.

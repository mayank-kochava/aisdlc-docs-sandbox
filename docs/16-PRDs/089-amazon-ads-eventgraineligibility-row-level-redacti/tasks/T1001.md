## Implementation Guide

1. In SanitizationApiClient.php, add `public $require_restriction_flag = false` as the last constructor argument of GetKeypathsResponse.
2. In retrieveKeyPaths, populate it from the API response with `(bool)($data['require_restriction_flag'] ?? false)`.
3. Add `require_restriction_flag` to the 15-minute cache payload. Read it back on a cache hit, defaulting to false for older cache entries.
4. Return false for require_restriction_flag on every error path.
5. Write failing tests first in SanitizationApiClientTest.php (API true, API omitted, cache hit, error path). Run them in the control-cover:ci image.

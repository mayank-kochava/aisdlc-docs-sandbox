## Summary
Implements per-conversion row-level redaction of Amazon Ads (network 13954) conversions, driven by Amazon's `eventGrainEligibility` value resolved to a single `row_level_restricted` flag at ingestion (fail-closed). The flag rides downstream as a claim dynamic field and drives masking in the BigQuery write-time redacted/raw split, MySQL detail workers, and postbacks, while aggregates read the unredacted copy. The feature reuses existing redaction machinery (Snap/TikTok/Reddit) and is gated by a single ingestion-layer enforce-from timestamp, deployed inert first and enabled last.
**Planning caveat (critical):** Only the ingestion decision point (ING) has a verified code home (watson `cmd/watson/amazonadssan`, from eng-research). Every other FR group's owning repository was never checked out and remains an Open Question — this plan scopes ING concretely and carries the rest as explicit, blocking Open Questions rather than guessing.

## Implementation Guide

1. On `kochava_reports.report_filtering`, SELECT the existing row for partner `amazon` to read its column names and its filter_columns value. Do not guess either; copy them from that row.
2. Write one SQL INSERT for partner `amazonadssan` that uses the same columns as the `amazon` row and copies its filter_columns value, as the provisional list per BR-16.
3. After T004 is complete, run the INSERT once.
4. Run `SELECT * FROM report_filtering WHERE partner IN ('amazon','amazonadssan')` and confirm exactly one `amazonadssan` row exists and its filter_columns equals the `amazon` row's.
5. Confirm no other report_filtering rows changed: compare the row count for all other partners before and after.

## Implementation Guide

1. Check whether `blacklistedDatasets` in cmd/query/blacklist.go already contains "unredacted".
2. In cmd/query/blacklist_test.go, add tests (failing first if the entry is missing) that run `unredacted_app_N` and `account_N_unredacted` through `GetTableAndDatasetsFromString` and the blacklist check.
3. Add the "unredacted" entry to `blacklistedDatasets` if it is missing (substring match).
4. Add a regression test that an ordinary dataset such as `app_N` is not blacklisted.
5. Run `go test ./cmd/query/...`.

## Acceptance Criteria

- WHEN a row's `install_original_request`, `click_original_request` or `ad_information` contains `"row_level_restricted":true` THE SYSTEM SHALL mask the configured Amazon columns in that row. [BR-4, FR-MYD-002]
- WHEN the flag is absent from those fields THE SYSTEM SHALL output the row unchanged. [BR-4]
- WHEN a configured string column is masked THE SYSTEM SHALL write `---`, and WHEN a numeric or time column is masked THE SYSTEM SHALL write NULL, with column types taken from the frozen QA list in the test fixture. [BR-7]
- WHEN a row is masked THE SYSTEM SHALL keep the row and leave non-Amazon and network/tracker columns unchanged. [BR-6, BR-8]
- WHEN the network has no restricted-flag rules THE SYSTEM SHALL leave every row unchanged. [BR-13]
- Existing tests pass
- New functionality has test coverage
- Code follows repository conventions (see CLAUDE.md)

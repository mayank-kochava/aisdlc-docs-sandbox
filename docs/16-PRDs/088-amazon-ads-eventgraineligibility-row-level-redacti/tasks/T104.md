## Implementation Guide

1. Before any create call, confirm the deployed sanitization-api already accepts require_restriction_flag. That support comes from T102, not T004. If it is missing, stop and flag the missing dependency instead of continuing.
2. Read pkg/routerPaths/routerPaths.go and find the existing route for creating a sanitization configuration. Use that registered path for the calls below and record it in the PR. Edit the file only if the route is missing or wrong, and do not invent a new path.
3. Run the sanitization-api create call for the 13954 restriction configuration with require_restriction_flag set.
4. Create the per-recipient keypath rows for reporting and postback from the provisional Amazon-sourced column list. The QA freeze (BR-16) has not happened yet, so mark them provisional.
5. Create the keypath row for the Amazon recipient so its own postback stays raw (provisional DEC-001 value).
6. Read every created row back from sanitization-api and attach the output to the PR. Leave AMAZON_ADS_EGE_ENFORCE_FROM unset.

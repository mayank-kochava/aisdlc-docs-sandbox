1. Open sendRequest in cmd/watson/amazonadssan/reconcile.go (around lines 400-436) and find where the response body is appended to sanLog.

4. Keep the response body parsing and return values unchanged.
5. Add response_log_test.go to assert the logged text contains the status and not the body.

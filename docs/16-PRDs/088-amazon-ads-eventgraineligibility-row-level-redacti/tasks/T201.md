## Implementation Guide

1. In internal/httpclients/sanitization/models/sanitization.go, add RequireRestrictionFlag bool `json:"require_restriction_flag"` to ConfigurationResponse.
2. In internal/process_postbacks.go, add IsRowLevelRestricted(postback *control.Postback) bool. It returns true only when postback.Kochava.Device.Attribution.Fields["row_level_restricted"] is a bool true. It must be nil-safe, return only a bool, and never log field values.
3. In internal/process_postbacks.go, find the existing code that applies a ConfigurationResponse to a postback. Apply it only when RequireRestrictionFlag is false (legacy) or IsRowLevelRestricted is true. Do not add new files.
4. Touch cmd/soccer-v2/main.go only as far as needed to wire this in.
5. Make sure nothing reads eventGrainEligibility, so the decision uses only row_level_restricted.
6. Add tests to cmd/soccer-v2/handler_test.go for: flag true, flag absent, flag not a bool, nil postback or nil Fields, a config without the option, and a config with the option set.

## Acceptance Criteria

- WHEN row_level_restricted is the bool true and the config sets require_restriction_flag THE SYSTEM SHALL apply the configured sanitization to the postback, and the test asserts the sanitized output. [BR-4, FR-BQR-002]
- WHEN row_level_restricted is absent or not a bool, or the postback or its Fields are nil, and the config sets require_restriction_flag THE SYSTEM SHALL leave the postback unsanitized without panicking. [BR-4, FR-BQR-004]
- WHEN the active-config JSON omits require_restriction_flag THE SYSTEM SHALL decode RequireRestrictionFlag as false and keep legacy sanitization behavior. [NFR-011, FR-ENF-006]
- WHEN a postback carries only an eventGrainEligibility value and no row_level_restricted field THE SYSTEM SHALL treat it as unrestricted. [BR-4, FR-BQR-001]
- WHEN IsRowLevelRestricted runs on a postback with Amazon attribution fields THE SYSTEM SHALL emit no log output containing those field values, and the test captures log output to assert this. [FR-AUD-003, NFR-008, FR-BQR-005]

## Implementation Guide

1. Read pkg/directmatch/getter.go, bigquery.go, directmatch.go and sql.go to find the existing code paths that query the analytic, restricted and skad sources. Reuse them unchanged, and do not rename or invent any of their symbols.
2. In pkg/directmatch/getter.go add `const unredactedSource = "unredacted"` and `const unredactedTable = "`%s.account_%d_unredacted.analytics`"`, plus `type lookupSource struct { name string; fn func(ctx context.Context, request MatchRequest, bq *bqGetter) (int64, error) }`.
3. Implement `getFromUnredactedAnalyticsTable(ctx, request, bq)`. Build its query the same way the existing analytic and restricted lookups do (pattern in bigquery.go and sql.go), using `unredactedTable`.
4. Add `lookupSources()` returning `lookupSource` entries in the order analytic, restricted, unredacted, skad. The analytic, restricted and skad entries must wrap the existing lookup functions you found in step 1.
5. Change the existing lookup flow in getter.go that currently calls those sources in sequence so it iterates `lookupSources()` and stops at the first match.
6. Extend pkg/directmatch/getter_test.go to cover the source order, a hit only in the unredacted table, and no unredacted query after an earlier hit.

## Acceptance Criteria

- WHEN a lookup finds no match in the analytic or restricted tables THE SYSTEM SHALL query `account_<id>_unredacted.analytics` before the skad source. [BR-9, FR-AGG-001]
- WHEN a match exists only in the unredacted analytics table THE SYSTEM SHALL return that match. [BR-9, FR-AGG-004]
- WHEN `lookupSources()` is called THE SYSTEM SHALL return the sources in the order analytic, restricted, unredacted, skad. [FR-AGG-001]
- WHEN a match is found in the analytic or restricted table THE SYSTEM SHALL return it without querying the unredacted table. [FR-ENF-006]

## Implementation Guide

1. In cmd/build/amazonadssan_config.go, add `EGEEnforceFrom int64` to AmazonAdsSANConfig, with a cli.Int64Flag named "amazonadssan-ege-enforce-from" and EnvVar "AMAZON_ADS_EGE_ENFORCE_FROM". Unix seconds; 0/unset means off. A malformed value must fail at startup.
2. In cmd/watson/amazonadssan/reconcile.go, add `applyRowLevelRestriction(claim waterfall.ClaimInterface, resp *response, enforceFrom int64)`.
3. Make it a no-op unless enforceFrom>0 and claim.Time().Unix()>=enforceFrom. Otherwise call resolveRowLevelRestricted (from T001).
4. When restricted, call SetDynamicField to set top-level "row_level_restricted"=true (bool) and "event_grain_eligibility"=<audit string>. Never set false; leave it unset when UNRESTRICTED.
5. Call it from buildMatchObj, passing the config value through. Ensure it runs only on the 13954 amazonadssan path.
6. Add cmd/build/amazonadssan_config_test.go (unset, valid, malformed) and cmd/watson/amazonadssan/restriction_wiring_test.go (truth table, before/after enforce-from, unset, 13954-only, no flag when UNRESTRICTED).

## Acceptance Criteria

- WHEN AMAZON_ADS_EGE_ENFORCE_FROM is unset or 0, THE SYSTEM SHALL set no row_level_restricted or event_grain_eligibility field on any claim. [BR-11, FR-ING-004, FR-ENF-004]
- WHEN claim time is earlier than enforce-from, THE SYSTEM SHALL leave the claim unflagged and shall not flag it later. [BR-12, FR-ING-004]
- WHEN enforcement is active and the resolved decision is restricted, THE SYSTEM SHALL set the top-level dynamic field row_level_restricted=true and record event_grain_eligibility as the audit value. [FR-ING-001, FR-ING-003, FR-ING-006, FR-AUD-001, NFR-009]
- WHEN enforcement is active and eventGrainEligibility is UNRESTRICTED, THE SYSTEM SHALL leave row_level_restricted unset and never write it as false. [FR-ING-002, BR-17]
- WHEN AMAZON_ADS_EGE_ENFORCE_FROM is malformed, THE SYSTEM SHALL fail at startup, and THE SYSTEM SHALL apply the logic only to network 13954. [FR-ING-005, BR-13, NFR-007]

## Steps

1. Create OnboardingTimelineService.cs in Kochava.Aim.Portal.Services/Onboarding/ and OnboardingTimelineController.cs in Kochava.Aim.Portal.Api/Areas/App/Controllers/. Do this after T007.
2. Implement PUT /{id}/timeline, allowed for both client and CSM (no CSM guard).
3. Support edits to milestone Status and Notes, and a delay edit that stores the new date as DelayedToDate. Return 400 for a bad date.
4. Implement the cascade recompute as a pure, testable function. Dates are anchor + WeekOffset, week-commencing Monday.
5. Append one ChangeLog entry per edit, with UserEmail stamped server-side from the session email and never taken from the request body.
6. Run dotnet build.

## Steps

1. Create OnboardingCsmService (Kochava.Aim.Portal.Services/Onboarding/OnboardingCsmService.cs) and OnboardingCsmController (Api/Areas/App/Controllers/OnboardingCsmController.cs).
2. Run OnboardingCsmGuard first in both operations, so a non-admin gets 403.
3. POST /{id}/approve sets ScopeOfWork.CsmApproved.
4. POST /{id}/tier-override sets Tier.Override, enforcing the asymmetric rule: X to Pro is allowed only when the auto tier is Pro. Reject other cases per the rule.
5. Append a mandatory ChangeLog entry for tier-override with the server-stamped user email (and record approve as well if the spec calls for it).
6. Map results through HandleDataUpdateResult and ForbidWithReason.

## Steps

1. Create Kochava.Aim.Portal.Services/Onboarding/OnboardingSowApprovalService.cs and Kochava.Aim.Portal.Api/Areas/App/Controllers/OnboardingSowApprovalController.cs. Start after T007.
2. Implement `PUT /{id}/sow-approval`. Reject with 409 if `CsmApproved` is not set.

## Steps

1. Create `OnboardingSowApprovalService` in `Kochava.Aim.Portal.Services/Onboarding/OnboardingSowApprovalService.cs` and `OnboardingSowApprovalController` in `Kochava.Aim.Portal.Api/Areas/App/Controllers/OnboardingSowApprovalController.cs`. Both are new per the plan. Start after T007.
2. Add `PUT /{id}/sow-approval`, with advertiser-level auth.
3. Return 409 if `CsmApproved` is not set.
4. On success set `ApproverName`, `ApproverJobTitle` and `ApprovedAt`, and set `Status = complete`.
5. Anchor the timeline by setting `Timeline.AnchorDate`.
6. Append a `ChangeLog` entry. There is no unlock, so later autosave PUTs return 409.

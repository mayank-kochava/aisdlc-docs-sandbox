2. Use CollectionNames.AimOnboardingSessions (T001).
3. Apply an AdvertiserId filter on every operation. GetLatestByAdvertiserAsync returns the most recent doc (latest wins, one doc per advertiser).
4. Implement ReplaceAsync as a single full-doc replace that returns a conflict result when the stored doc has ApprovedAt set.

6. Make sure the class is picked up by Autofac auto-registration, with no manual registration unless SavedViews needs one.

## Steps

1. In `output/SowTab.vue`, render the generated sections in the mono document style from the composable state (including objectives), with a tier band showing the effective tier.
2. Add inline notes per section, bound to `ScopeOfWork.SectionNotes`, that stay editable after approval.
3. Persist notes through the existing `onboarding` service. Before wiring, check which endpoint carries `SectionNotes`, because autosave PUT returns 409 once `ApprovedAt` is set.
4. Add the approval block: approver name and job title inputs, and a timestamp (`ApprovedAt`) once approved. The approval action calls `PUT /{id}/sow-approval`, which returns 409 unless `CsmApproved` is set.
5. Disable the approval action until `CsmApproved`, and show the API's 409 message clearly.

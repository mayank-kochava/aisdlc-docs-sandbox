## Steps

1. Open `output/TimelineTab.vue` and build it on a bare `v-data-table`.
2. Show 6 milestones with computed dates: `anchor (approvedAt) + weekOffset`, week-commencing Monday, computed client-side and not stored.
3. Add a status select per milestone. For a delay, show a preview of the new date, then a confirm step, then the cascade to later milestones.
4. Save changes via `PUT /{id}/timeline` and show the audit-log view from `ChangeLog`. Show an error on a 400 bad date.
5. Add the CSM tier-override toggle. Show it only when `isASAdmin` is true and call `POST /{id}/tier-override`. Handle a 403 without breaking the UI and respect the override rule in the contract table.
6. Make the milestone and status controls keyboard-accessible.

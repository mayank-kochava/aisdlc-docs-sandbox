## Steps

1. In `output/TimelineTab.vue`, build a bare `v-data-table` of the 6 milestones. Compute est. dates client-side as anchor (`approvedAt`) + `weekOffset`, week-commencing Monday. Do not store them.
2. Add a status select per row, saved through `PUT /onboarding-sessions/{id}/timeline`.
3. Implement delay as: pick a new date, preview the new date and its cascade effect on later milestones, then confirm. Handle a 400 bad-date response.
4. Add an audit-log view of `ChangeLog`.
5. Add the CSM tier-override toggle, shown only when `isASAdmin`. It calls `POST /{id}/tier-override` and shows a clear message on 403 or a rejected override.
6. Use theme tokens only.

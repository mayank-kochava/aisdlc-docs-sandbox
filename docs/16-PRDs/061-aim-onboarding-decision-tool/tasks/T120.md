## Steps

1. Edit `output/TimelineTab.vue` as a bare `v-data-table` with the 6 milestones (name, responsible, computed date, status select).
2. Compute the dates client-side as anchor (`approvedAt`) + `weekOffset`, week-commencing Monday; do not store computed dates.
3. Add status editing and a delay flow: pick a new date, preview the cascade, then confirm before calling `PUT /{id}/timeline` (400 on a bad date).
4. Add an audit-log view driven by `ChangeLog`.
5. Add the CSM tier-override toggle (`POST /{id}/tier-override`), shown only when `isASAdmin` is true and handling 403 gracefully.
6. Respect the rule that an X-to-Pro override is allowed only if the auto tier is Pro.

## Steps

1. In `output/TimelineTab.vue`, render a bare `v-data-table` with the 6 milestones. Compute dates as the anchor plus `WeekOffset`, week-commencing Monday, anchored on `approvedAt`.
2. Add a status select per milestone that saves through `PUT /{id}/timeline`.
3. Implement delay as: enter a new date, preview the resulting dates including the cascade, then confirm before saving. Handle a 400 for a bad date.
4. Add an audit-log view that lists `ChangeLog` entries.
5. Add the CSM tier-override toggle behind `isASAdmin`, calling `POST /{id}/tier-override` and handling 403 without breaking the UI. Allow X to Pro only when the auto tier is Pro.
6. Do not send author or user identity in the payload, because `UserEmail` is server-stamped.

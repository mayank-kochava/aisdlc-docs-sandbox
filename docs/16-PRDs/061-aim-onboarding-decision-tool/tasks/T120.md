## Steps

1. Build `output/TimelineTab.vue` as a bare `v-data-table` with the 6 milestones. Compute dates as `anchor + weekOffset`, anchored on `approvedAt` and shown week-commencing Monday.
2. Add a per-row status select. For delays, show the new date as a preview and require confirmation before saving.
3. Implement the cascade of a delay across later milestones (the plan flags this date math as a risk) and show the cascaded dates in the preview before confirm.
4. Add the audit-log view rendered from `ChangeLog`.
5. Add the CSM tier-override toggle, shown only when `isASAdmin` is true. On 403 revert the toggle and show a message, and honor the rule that X to Pro is allowed only if the auto tier is Pro.
6. Handle a 400 (bad date) from `PUT .../timeline` with an inline error.

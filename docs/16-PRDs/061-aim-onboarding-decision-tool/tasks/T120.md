## Steps

1. Implement `output/TimelineTab.vue` as a bare `v-data-table` with the 6 milestones.
2. Compute each date as `approvedAt` (the anchor) plus `weekOffset`, shown as the week-commencing Monday. Do not store computed dates.
3. Add a status select per row and a delay flow: pick a new date, preview it, then confirm. Apply the cascade to later milestones and save via `PUT .../timeline`, surfacing 400 on a bad date.
4. Add an audit-log view of `ChangeLog` entries.
5. Add the CSM tier-override toggle shown only when `isASAdmin`. Handle 403 and the rule that X is allowed only when the auto tier is Pro.

- [ ] The tier-override toggle is hidden for non-CSM users and shows an error message on 403.
- [ ] A 400 response for a bad date is shown to the user.

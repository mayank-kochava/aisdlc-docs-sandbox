## Steps

1. Add an AdminResolver in Kochava.Aim.Portal.Common/Identity/AdminResolver.cs that calls the mos-iam GetUserByEmail client and reads is_as_admin. The file is listed as modify but the plan treats it as new, so create it if absent.
2. Pass the x-user-id value to the resolver as the email, since x-user-id is the email.
3. Cache the lookup result. On lookup failure or timeout, fail closed and return false.
4. Add IsAsAdmin to ICurrentUserContext in Kochava.Aim.Portal.Common/Identity/ICurrentUserContext.cs.
5. Populate IsAsAdmin in Kochava.Aim.Portal.Api/Filters/AdvertiserContextActionFilter.cs.
6. Confirm the mos-iam GetUserByEmail client is available to portal-api. The plan lists this dependency as open; flag it if it is missing rather than inventing a client.

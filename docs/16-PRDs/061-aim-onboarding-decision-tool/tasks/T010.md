## Steps

1. Create Kochava.Aim.Portal.Common/Identity/AdminResolver.cs if it does not exist. Have it call mos-iam `GetUserByEmail`, using the `x-user-id` header value as the email, and read `is_as_admin`.
2. Cache the resolved result in AdminResolver.
3. Make AdminResolver fail closed: if the lookup errors or times out, or the user is not found, return false.
4. Add `IsAsAdmin` to `ICurrentUserContext` in Kochava.Aim.Portal.Common/Identity/ICurrentUserContext.cs.
5. Populate `IsAsAdmin` in Kochava.Aim.Portal.Api/Filters/AdvertiserContextActionFilter.cs via the resolver.
6. Confirm the mos-iam client is available to portal-api. The plan lists this as an open dependency, so flag it if it is missing.

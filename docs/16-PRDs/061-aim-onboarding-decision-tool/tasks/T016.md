## Steps

1. Create `Kochava.Aim.Portal.Tests/OnboardingPrivilegedOpsTests.cs` using NUnit, Moq and FluentAssertions. Build it against the services and controllers from T012, T013 and T015, and mock the mos-iam `is_as_admin` resolver and the data layer.
2. Add a 403 test for a non-admin calling `approve`. Add another for a non-admin calling `tier-override`. Both go through `OnboardingCsmGuard`, and `DataUpdateResult.AccessDenied` must map to 403.
3. Add an admin-path test for each of the two ops to show they succeed when the resolver returns admin. Add a fail-closed test where the resolver errors or denies.
4. Add a timeline-edit test asserting a `ChangeLog` entry is appended with `UserEmail` equal to the session email, not a client-supplied value.
5. Add `sow-approval` tests. It returns 409 if `CsmApproved` is false. When it succeeds it sets `Status=complete` and locks the session (`ApprovedAt` set).
6. Add cascade-math cases: a milestone delay shifts later milestones by `anchor + weekOffset`, dates fall on a week-commencing Monday, and a bad date returns 400.

## Steps

1. Extend `useAimOnboarding.ts`. Start only after T108 is in place.
2. On mount, call `onboardingService.getLatest` and hydrate state. Handle 404 as no session. Fall back to the localStorage buffer if needed.
3. Write state to a localStorage buffer on change. Debounce the full-doc `update` PUT, and also flush it on step switch, tab switch and manual save.

6. Handle 409 after approval by stopping autosave and surfacing the locked state.

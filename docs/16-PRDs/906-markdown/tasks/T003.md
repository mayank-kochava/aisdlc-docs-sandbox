## Implementation Guide

1. Create ratelimit/example_test.go with `package ratelimit_test` (an external test package, so the code calls `ratelimit.New` as a library user would).
2. Import `fmt`, `time` and `github.com/mayank-kochava/coding-agent-sandbox/ratelimit`.
3. Define `func Example()` that builds a clock with ratelimit.NewFakeClock(time.Now()) and a limiter with ratelimit.New(1, 2, clock).
4. Call Allow() three times, printing each result with fmt.Println. Then call clock.Advance(time.Second), call Allow() once more and print the result.
5. Add the `// Output:` block with the lines true, true, false, true.
6. Run go vet ./... and go test -race ./ratelimit/ -run Example

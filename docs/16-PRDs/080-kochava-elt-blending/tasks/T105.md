## Implementation Guide

1. Prerequisite: the store calls `services/blends.ts` (T103) and uses the Blend types (T102). Run it after both, not only after T104.
2. Create `stores/blends.ts` in `packages/data-connect/src/` as a Pinia store.
3. Use `stores/pipelines.ts` only as a reference. Do not edit it.
4. Add state and actions for loading, creating, updating, duplicating and deleting blends, calling `services/blends.ts`.
5. On failure, report through `notificationsStore.addNotification`, copying the pattern in `stores/pipelines.ts`.
6. Write `stores/blends.spec.ts` with `services/blends.ts` mocked.

## Implementation Guide

1. Identify who owns the key-prefix scheme of the shared GCS storage bucket.
2. Ask the owner to confirm `blend-staging/` as the prefix for Parquet staging data. It mirrors the existing log/state/workloadOutput/activityPayload/auditLogging separation.
3. Compare `blend-staging/` with those five existing prefixes and confirm there is no overlap.
4. Record the owner's name, the decision and the final prefix string in the issue. If the owner picks a different prefix, record that instead.
5. No repository file is edited. `blend-staging` in the task's file list is a GCS key prefix, not a file.

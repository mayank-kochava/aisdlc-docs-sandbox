## Implementation Guide

1. Preconditions (not declared in `depends_on`, so check them yourself): T033 (`BlendCombineJobPodFactory.kt`) must be merged so you can read the node selector and `blend-combine-workload` toleration it sets, and T201 must be merged so the new pool name and taint exist in `greedy_goat.tf`. 3. If needed, edit only `ko-k8s-apps/airbyte/app/qa/release.yaml` to add a `nodeSelector` for the new pool and a toleration for the `blend-combine-workload` taint. Copy the pool name and taint key verbatim from `greedy_goat.tf`.
4. Leave the existing `airbyte-workload` toleration and the `s-n4-std-8-airbyte` placement for sync/check/discover/spec jobs unchanged.
5. Keep the change QA-only: no prod overlay edits.

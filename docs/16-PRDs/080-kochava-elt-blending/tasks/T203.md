## Implementation Guide

1. Do not start until T201 (it defines the dedicated pool name and the `blend-combine-workload` taint) and T033 (`BlendCombineJobPodFactory.kt`) are merged. Neither is a declared dependency, so confirm both first.
2. Read the pod spec in `BlendCombineJobPodFactory.kt` and note the `nodeSelector` and toleration it already sets, including the `blend-combine-workload` toleration.
3. If the pod spec already covers scheduling and the chart needs nothing more, leave `ko-k8s-apps/airbyte/app/qa/release.yaml` unchanged and note 'no change needed' on the issue. Stop here.
4. Otherwise edit `ko-k8s-apps/airbyte/app/qa/release.yaml` to add a `nodeSelector` and a toleration. They must match the pool name and `blend-combine-workload` taint defined in T201. Only add lines and do not remove any existing ones.
5. Change only the QA file `ko-k8s-apps/airbyte/app/qa/release.yaml`. The prod overlay is out of scope for this initiative.
6. Check that the YAML still parses and have SRE review the diff.

## Implementation Guide

1. Prerequisite: the store calls `services/canonicalMappings.ts` (T104) and uses the types from T102. Run it after both.
2. Create `stores/canonicalMappings.ts` in `packages/data-connect/src/` as a Pinia store.
3. Add state and actions that load and save mappings via `services/canonicalMappings.ts`.
4. Report errors through `notificationsStore.addNotification`, the same way `stores/pipelines.ts` does.
5. Write `stores/canonicalMappings.spec.ts` with the service mocked.

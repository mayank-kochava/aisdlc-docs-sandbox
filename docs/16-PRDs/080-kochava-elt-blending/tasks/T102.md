## Implementation Guide

1. Open `types/index.ts` in `packages/data-connect/src/`.
2. Take the field names and shapes for each type from `contracts/api.yaml` in the PRD folder (the OpenAPI spec). Do not invent fields.
3. Add the types `Blend`, `BlendType`, `BlendMembership`, `CanonicalField`, `CanonicalMapping`, `JoinDirection`, `JoinKeyPair`, `UnionRowIdentity`, `PerMetricAggregationRule` and `PartialFailurePolicy`.
4. Model `BlendType` as Union or Join, and `JoinDirection` as Inner, Left, Right or Full outer. Include the dimension-vs-metric classification on `CanonicalField` as the contract defines it.
5. Export all ten types without changing existing ones.
6. Add a type-level test file `types/index.test-d.ts` using vitest's `expectTypeOf`, so the exports and the value restrictions are checked at compile time.

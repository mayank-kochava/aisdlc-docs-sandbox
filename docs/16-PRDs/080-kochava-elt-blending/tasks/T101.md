## Implementation Guide

1. Prerequisite: the route targets `BlendsList.vue` and `BlendWizard.vue` are created by T107 and T108. Run this task after both, or the routes will point at missing files.
2. Open `router/index.ts` in `packages/data-connect/src/`.
3. Add a route for `/dataconnect/blends` pointing to `BlendsList.vue`.
4. Add a route for `/dataconnect/blends/new` pointing to `BlendWizard.vue`.
5. Copy the naming, import style and structure of the existing pipeline route entries.
6. Write `router/index.spec.ts` to check that both paths resolve to the new routes.

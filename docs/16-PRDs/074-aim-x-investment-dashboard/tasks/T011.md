## Implementation Guide

1. Create Kochava.Aim.Portal.Services/InvestmentDashboardService.cs.
2. Follow the multi-scope pattern of CostCurvesController.cs.
3. Read per-network targets and pacing, plus raw daily spend records (DateSpend), through the data layers.
4. Return raw daily time-series data so MTD and daily figures are computed on the frontend.
5. Map results to NetworkPacingDto via the AutoMapper profile from T010.
6. Add unit tests in Kochava.Aim.Portal.Tests/InvestmentDashboardServiceTests.cs using NUnit, Moq and FluentAssertions.

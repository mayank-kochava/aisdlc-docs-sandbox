## Implementation Guide

1. Create `packages/advertiser/src/views/AimInvestmentDashboard/composables/useAimTour.ts`, following the approach decided in T152.
2. Define the tour step list and the reactive state: active, current step, start, next, previous, and finish/skip.
3. Expose start/stop controls so `InvestmentDashboard.vue` and the Help flow (T156) can call them.
4. Leave a clear hook for the 'seen' flag, which T154 adds.
5. Keep the tour lazy-loaded with the dashboard route so it does not grow the 910kB gzip main chunk.

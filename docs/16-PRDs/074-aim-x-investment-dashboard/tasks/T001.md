## Implementation Guide

1. Create Kochava.Aim.Portal.Tests/Integration/TestServerFixture.cs.
2. Build the fixture on WebApplicationFactory so it hosts the mmm-portal-api app in-process.
3. Expose an HttpClient from the fixture for tests to use.
4. Make the fixture work with the existing NUnit setup in Kochava.Aim.Portal.Tests.
5. Add one smoke test that starts the host and makes a request, to prove the fixture works.

## Implementation Guide

1. Add a WebApplicationFactory-based integration test harness to Kochava.Aim.Portal.Tests. The portal API has none today, and the task gives no file path, so choose a new file there.
2. Point the harness at the app with the Mongo data layer replaced by a test double or fixture.
3. Add tests that call the NetworkIntelligenceController endpoint(s) and assert the status code and response shape.
4. Add a test that calls the endpoint for a key with no data and asserts the empty-state response.
5. Run the new integration tests together with the existing suite.

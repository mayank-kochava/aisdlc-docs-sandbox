## User Story

**US1**

**Acceptance:**
- FR-2: `retry.Do(ctx, p Policy, maxAttempts int, sleep Sleeper, fn func() error) error` calls `fn` until it returns nil, the attempts run out, or `ctx` is cancelled. It returns the last error, or `ctx.Err()` on cancel.
- FR-3: `retry.Permanent(err)` wraps an error so `Do` stops at once and returns the wrapped error (unwrapped via `errors.Is`/`errors.As`).
- FR-4: Default attempts: `maxAttempts <= 0` uses a default chosen by the owner (Mayank). The number is **not written in this document**; the coding agent must ask the owner and must not guess.
- FR-5: Sleeping goes through a `Sleeper` interface so tests use a fake sleeper and never sleep.

## Implementation Guide

1. BLOCKER for the default: ask the owner (Mayank) for the default attempt count used when `maxAttempts <= 0` (FR-4). Do not guess or invent it. If no answer is available, stop and report. Do not commit any placeholder number. Once received, define it as one named constant in `retry/retry.go` (e.g. `DefaultMaxAttempts`) and note the owner's answer in the PR description.
2. Create `retry/retry.go` with `func Permanent(err error) error`. It returns a wrapper type that implements `Unwrap()`, so `errors.Is` and `errors.As` work on the wrapped error.
3. Implement `func Do(ctx context.Context, p Policy, maxAttempts int, sleep Sleeper, fn func() error) error`. If `maxAttempts <= 0`, use the named default constant. If `sleep == nil`, use `RealSleeper()`.
4. In the loop, check `ctx.Err()` before each attempt and return it if set. Call `fn` and return nil on success. On a `Permanent` error, stop at once and return the wrapped (inner) error.
5. Between attempts, call `sleep.Sleep(ctx, p.Delay(n))` and return its error if non-nil. Do not sleep after the final attempt. When attempts run out, return the last error from `fn`.
6. Write table-driven tests in `retry/retry_test.go` using `FakeSleeper`, covering: success on the Nth try, exhausted attempts returning the last error, Permanent stopping after one call with `errors.Is` and `errors.As` working, ctx cancel returning `ctx.Err()`, recorded delays, nil sleeper, and `maxAttempts` of 0 and -1. The default-count test must assert the call count equals the named constant, not a hardcoded number. Use the standard library only.

## Acceptance Criteria

- WHEN `fn` fails on every attempt THE SYSTEM SHALL call `fn` exactly `maxAttempts` times and return the last error from `fn`. [FR-2]
- WHEN `ctx` is cancelled THE SYSTEM SHALL stop retrying and return `ctx.Err()`. [FR-2]
- WHEN `fn` returns an error wrapped by `Permanent` THE SYSTEM SHALL call `fn` once and return the wrapped error, matchable via `errors.Is` and `errors.As`. [FR-3]
- WHEN `maxAttempts <= 0` (tested with 0 and -1) and `fn` always fails THE SYSTEM SHALL call `fn` exactly the named default-constant number of times, and that constant SHALL equal the value the owner confirmed (recorded in the PR description). [FR-4]
- WHEN `fn` fails and attempts remain THE SYSTEM SHALL sleep only through the `Sleeper`, so a `FakeSleeper` records `p.Delay(n)` between attempts and nothing after the final attempt. [FR-2, FR-5]

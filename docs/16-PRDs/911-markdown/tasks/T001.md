# T001: Backoff policy and sleeper

## In short

Adds the timing rules for retries: how long to wait before each new attempt, growing each time up to a maximum. It also adds a swappable "waiter" so tests can check the waits without actually waiting.

## Engineering plan
- **Repository:** `mayank-kochava/coding-agent-sandbox` (Go module `github.com/mayank-kochava/coding-agent-sandbox`, Go 1.22). Every task targets this repo.
- **Design:** `Policy` is a plain value type. `Do` loops, sleeps `p.Delay(n)` between attempts via `Sleeper.Sleep(ctx, d) error` (returns `ctx.Err()` if cancelled while waiting), and stops early on a `Permanent` error.
- **Stack:** Go standard library only. No new dependencies, no `go.mod` changes.
- **Testing:** table-driven tests with a fake sleeper that records delays; `go test -race ./...` passes, `go vet` clean.

## Implementation Guide

1. Create `retry/policy.go` in package `retry` with `type Policy struct{ Base, Max time.Duration; Factor float64 }`.
2. Implement `func (p Policy) Delay(attempt int) time.Duration` returning `Base * Factor^(attempt-1)`, capped at `Max`. Treat `attempt < 1` as 1. Compute in float64 and cap before converting to `time.Duration`.
3. Declare `type Sleeper interface{ Sleep(ctx context.Context, d time.Duration) error }`.
4. Implement `RealSleeper() Sleeper`. It waits for `d` and returns `ctx.Err()` if `ctx` is cancelled while waiting.
5. Implement `type FakeSleeper struct{ Delays []time.Duration }` and `func (f *FakeSleeper) Sleep(ctx context.Context, d time.Duration) error`. It appends `d` to `Delays` and never sleeps.
6. Write table-driven tests in `retry/policy_test.go` for `Delay`: attempt 1 equals Base, growth by Factor, cap at Max, and attempt 0 or negative treated as 1. Add a `FakeSleeper` recording test. Use the standard library only and make no `go.mod` changes.

## Acceptance Criteria

- WHEN `Delay(1)` is called on a Policy with Base 100ms THE SYSTEM SHALL return 100ms. [FR-1]
- WHEN `Delay(n)` is called with n > 1 THE SYSTEM SHALL return `Base * Factor^(n-1)`. [FR-1]
- WHEN the computed delay exceeds `Max` THE SYSTEM SHALL return `Max`. [FR-1]
- WHEN `Delay` is called with attempt < 1 THE SYSTEM SHALL treat it as attempt 1. [FR-1]
- WHEN `FakeSleeper.Sleep` is called with a duration THE SYSTEM SHALL append it to `Delays` and return without actually sleeping. [FR-5]
- Existing tests pass
- New functionality has test coverage
- Code follows repository conventions (see CLAUDE.md)

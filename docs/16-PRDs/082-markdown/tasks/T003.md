## In short

Adds a database table that records, for each smartlink, whether cross-platform attribution is switched on (off by default) and when it changed. This gives the toggle somewhere to store its state.

## Implementation Guide

1. List docker/mysql/ and identify the highest-numbered existing migration. Note its naming pattern, numbering width and SQL style (quoting, engine, charset, timestamp defaults).
2. Create the next-numbered migration file in docker/mysql/ using that naming pattern. The file name must contain cross_platform_attribution_settings, and the file holds a CREATE TABLE for that table.
3. Define the columns smartlink_id, enabled (default off/0), enabled_at, app_group_valid, created_at and updated_at. Match the column types used for similar fields in neighbouring migrations, and give smartlink_id the same type as kochava_links.smartlinks.id.
4. Add a foreign key from smartlink_id to kochava_links.smartlinks.id, using the FK syntax of the existing migrations.
5. Run the test_cmd below to check the new file's contents. Also, if the Makefile, CI config or a *_test.go file already runs a check over docker/mysql/ migrations, run it and fix any failure. Do not edit existing migrations.

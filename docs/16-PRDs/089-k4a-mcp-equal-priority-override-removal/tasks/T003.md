This module implements MCP tools for managing Kochava advertiser apps:

  the account's currency/timezone

  through separate mechanisms in the UI and are explicitly NOT supported here --
  see kochava_update_app's docstring for why each is out of scope.
- kochava_get_app_group_memberships / kochava_update_app_groups: read and update
  which dashboard organizational App Groups an app belongs to. This is a DIFFERENT
  concept from links-api's SmartLink app groups (smartlink_tools.py's
  kochava_list_app_groups/kochava_create_smartlink) -- same generic name, unrelated
  backend, unrelated ids. Split out from kochava_update_app because sprinkler-api
  has no endpoint that changes group membership alone without also re-submitting
  the app's entire settings record, which requires a fundamentally different
  (read-full-app-then-resubmit) safety approach than kochava_update_app's simple
  field-presence merge -- see kochava_update_app_groups's docstring for the details.

Note: currency and timezone are account-level (per user), not app-level, in this API --
there is no app-level field for either, and no write path exists for them here.

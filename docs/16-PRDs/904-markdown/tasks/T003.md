## Implementation Guide

1. Create lru/example_test.go with `func Example()`. Use package `lru_test` and import `github.com/mayank-kochava/coding-agent-sandbox/lru` (and `fmt`).
2. In Example, build `c := lru.New(2)`, then `Put("a", ...)`, `Put("b", ...)`, `Get("a")`, and `Put("c", ...)`.
3. Print the results of `Get("a")`, `Get("b")` and `Get("c")` with fmt.Println so the output shows that b was evicted while a and c remain.
4. Add a trailing `// Output:` block that exactly matches what is printed.
5. Run `go test ./lru/...` and `go vet ./...` and fix any output mismatch. Do not change T001 or T002 files.

1. Write `shortener/store_test.go` (package `shortener`) with these failing tests:
- `TestDeriveCode` (table): the same URL and attempt give the same result. The result has length 6 and only `[0-9A-Za-z]`. Attempt 0 differs from attempt 1 for the same URL.
- `TestSaveLookup`: `code := s.Save("example.com)` has length 6, and `Lookup(code)` returns the URL and `true`. `Lookup("zzzzzz")` returns `"", false`.
- `TestSaveIdempotent`: two `Save` calls with one URL return the same code (FR-4).
- `TestSaveCollision`: set `s.codeFn = func(u string, a int) string { if a == 0 { return "AAAAAA" }; return fmt.Sprintf("B%05d", a) }`. Then `c1 := s.Save("a")` and `c2 := s.Save("b")`. Assert `c1 != c2`, that each code looks up its own URL, and that a second `Save("b")` returns `c2`.
- `TestSaveConcurrent`: 50 goroutines call `Save` on a mix of identical and distinct URLs. Assert no panic, and that identical URLs got identical codes.
2. Run `go test ./shortener/...` and confirm a compile failure (undefined `NewStore`).
3. Implement `shortener/store.go`:
- `Store` has `mu sync.RWMutex`, `byCode map[string]string`, `byURL map[string]string` and `codeFn`.
- `deriveCode(url, attempt)` hashes `url` when `attempt == 0`, or `url + strconv.Itoa(attempt)` otherwise, with `crypto/sha256`. It converts the digest with `new(big.Int).SetBytes(sum[:]).Text(62)` and returns the first 6 characters.
- `Save` takes the write lock. If `byURL[url]` exists it returns that code. Otherwise it loops `attempt := 0; ; attempt++`. It computes `code := s.codeFn(url, attempt)`, and if `byCode[code]` is absent it records both maps and returns. If the code is taken (necessarily by a different URL, since the same URL was already handled), it continues.
- `Lookup` takes the read lock.
4. Run `go vet ./... && go test -race ./...` and confirm green.
5. Commit: `git add shortener/store.go shortener/store_test.go && git commit -m "feat(shortener): add in-memory store with deterministic collision-safe codes"`

## Acceptance Criteria

- WHEN `Save` is called with a URL THE SYSTEM SHALL return a 6-character code made only of [0-9A-Za-z], and `Lookup` of that code SHALL return the URL and true [FR-1]
- WHEN `Lookup` is called with a code that was never saved THE SYSTEM SHALL return an empty string and false [FR-3]
- WHEN `Save` is called twice with the same URL THE SYSTEM SHALL return the same code both times [FR-4]
- WHEN `codeFn` is forced to return the same code for two different URLs THE SYSTEM SHALL assign them different codes, each resolving to its own URL, and a repeated `Save` of the second URL SHALL return its original code [FR-1]
- WHEN 50 goroutines call `Save` concurrently with a mix of identical and distinct URLs THE SYSTEM SHALL not panic or race and SHALL return identical codes for identical URLs [FR-4]
- Existing tests pass
- New functionality has test coverage
- Code follows repository conventions (see CLAUDE.md)

## Implementation Guide

1. Open Dockerfile and confirm that ARG VERSION=dev and ARG PKG_VER_PATH=github.com/Kochava/gopkgver.Version are declared (lines 3-4).
2. Confirm the Go build step passes VERSION into the binary through a linker -X flag that uses PKG_VER_PATH, so gopkgver.Version (read via app.Version at cmd/household-id-adornment-api/main.go:20) receives it.
3. If the linker flag is missing or wrong, modify only Dockerfile to add it, and keep the default VERSION=dev when no build-arg is given.
4. If both checks already pass, leave Dockerfile unchanged.
5. Run the test_cmd. Its grep checks cover the Dockerfile and its go test covers T001's "dev" rendering.

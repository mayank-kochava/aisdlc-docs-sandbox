## Implementation Guide

1. In internal/healthcheck/healthcheck.go, change HealthHandler() to HealthHandler(version string) http.Handler.
2. Where the handler is built, replace an empty version with "dev".
3. Keep the existing behavior: write 200, then the body "OK - <host> - version <version>". Leave the existing hostname lookup and its "unknown" fallback untouched.
4. In internal/commands/server/server.go, pass cliCtx.App.Version (already read near line 103) to HealthHandler.
5. In internal/commands/reader/reader.go, pass cliCtx.App.Version (already read near line 89) to HealthHandler.
6. In internal/healthcheck/healthcheck_test.go, add httptest cases for a set version ("1.2.3") and an empty version. Assert status 200, the "OK - " prefix, and the exact " - version <v>" suffix.

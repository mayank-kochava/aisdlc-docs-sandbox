## Implementation Guide

1. Confirm T001 and T002 are in the working branch. Rebuild `hid:test` (`--build-arg VERSION=1.2.3`) and `hid:nover` (no build arg).
2. Read the Dockerfile ENTRYPOINT/CMD and the flags in internal/commands/server/server.go to find the `server` command arguments and the port `/healthcheck` is served on. The plan notes an 8080 vs 8787 discrepancy, so use the port the code actually uses.
3. Start each image detached with `docker run -d -p <host-port>:<container-port> <image> server <required flags>`, mapping them to `HID_PORT_TEST` (hid:test) and `HID_PORT_NOVER` (hid:nover). If the server needs external dependencies that cannot run locally, note this in the PR.
4. Run `curl -i` against `/healthcheck` on both containers. Confirm status 200, the `OK - ` prefix, `1.2.3` for hid:test and `dev` for hid:nover.
5. Paste the curl output into the PR description. Add the DEC-003 sign-off link, which the task names but the plan does not define, so get it from the task owner (NFR-002, NFR-003). Then stop the containers.
6. Run the test_cmd while both containers are still running. It runs the unit tests and the curl checks together.

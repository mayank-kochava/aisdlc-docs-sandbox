## Implementation Guide

1. In internal/healthcheck/healthcheck.go, change `HealthHandler()` to `HealthHandler(version string) http.Handler`. Keep returning an `http.HandlerFunc`, and capture `version` in the closure so nothing is looked up per request.
2. Keep status 200 and the existing `OK - <hostname>` body prefix, reusing the existing hostname logic. Append ` - ` plus `version` after the prefix, so the body is `OK - <hostname> - <version>`. Write only the bare version string, with no other build details.
3. In internal/commands/server/server.go (around line 166), change the call to `HealthHandler(cliCtx.App.Version)`. `cliCtx` is captured by the goroutine closure.
4. In internal/commands/reader/reader.go (around line 154), make the same change and pass `cliCtx.App.Version`. Do not miss this second call site.
5. Create internal/healthcheck/healthcheck_test.go using `httptest` and testify. For `HealthHandler("1.2.3")` and `HealthHandler("dev")`, assert status 200, the body starts with `OK - `, and the body ends with the version. Call the same handler several times and assert the version is identical each time.
6. Run the test_cmd. It runs the unit tests, then `go build ./...` to prove both commands compile against the new signature, then greps both call-site files for `HealthHandler(cliCtx.App.Version)`.

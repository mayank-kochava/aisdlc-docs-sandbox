## Engineering plan
- **Repository:** `mayank-kochava/coding-agent-sandbox` (Go module `github.com/mayank-kochava/coding-agent-sandbox`, Go 1.22). Every task targets this repo.
- **Design:** `Policy` is a plain value type. `Do` loops, sleeps `p.Delay(n)` between attempts via `Sleeper.Sleep(ctx, d) error` (returns `ctx.Err()` if cancelled while waiting), and stops early on a `Permanent` error.
- **Stack:** Go standard library only. No new dependencies, no `go.mod` changes.
- **Testing:** table-driven tests with a fake sleeper that records delays; `go test -race ./...` passes, `go vet` clean.

## Implementation Guide

1. Create retry/example_test.go (the only file; there is no non-test source file) with `package retry_test`, importing context, fmt, time and `github.com/mayank-kochava/coding-agent-sandbox/retry`.
2. Declare `func Example()` that builds `retry.Policy{Base: 100*time.Millisecond, Max: time.Second, Factor: 2}` and `s := &retry.FakeSleeper{}`, qualifying every package symbol with `retry.`.
3. Call `retry.Do(context.Background(), p, 3, s, fn)` with an fn that increments a counter, prints `attempt N` for each call, returns an error on attempts 1 and 2 and nil on attempt 3.
4. After Do returns nil, print `ok`, then print `s.Delays` with fmt.Println.
5. Add an `// Output:` block with exactly: attempt 1, attempt 2, attempt 3, ok, [100ms 200ms].
6. Run the example with the test command and confirm it passes without real sleeping.

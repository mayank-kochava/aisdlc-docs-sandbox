## User Story

**US1**

**Acceptance:**
- FR-2: `retry.Do(ctx, p Policy, maxAttempts int, sleep Sleeper, fn func() error) error` calls `fn` until it returns nil, the attempts run out, or `ctx` is cancelled. It returns the last error, or `ctx.Err()` on cancel.
- FR-3: `retry.Permanent(err)` wraps an error so `Do` stops at once and returns the wrapped error (unwrapped via `errors.Is`/`errors.As`).
- FR-4: Default attempts: `maxAttempts <= 0` uses a default chosen by the owner (Mayank). The number is **not written in this document**; the coding agent must ask the owner and must not guess.
- FR-5: Sleeping goes through a `Sleeper` interface so tests use a fake sleeper and never sleep.

## Implementation Guide

1. BEFORE writing code, ask the owner (Mayank) for the default attempt count used when maxAttempts <= 0. FR-4 says the number is not in the spec, so do not guess or invent a value. Stop and wait for the answer.
2. Create retry/retry.go in package retry, reusing Policy, Sleeper, FakeSleeper and RealSleeper from retry/policy.go (T001). Store the owner's number in a single named constant.
3. Implement `func Permanent(err error) error`, returning a wrapper type that implements Unwrap so errors.Is/errors.As reach the original error.
4. Implement `func Do(ctx context.Context, p Policy, maxAttempts int, sleep Sleeper, fn func() error) error`. If maxAttempts <= 0, use the default constant. If sleep is nil, use RealSleeper().
5. In Do, loop: return ctx.Err() if ctx is cancelled; call fn; return nil on success; on a Permanent error return the unwrapped error at once; otherwise call sleep.Sleep(ctx, p.Delay(n)) between attempts, returning ctx.Err() if it fails. After the final attempt return the last error.
6. Write table-driven tests in retry/retry_test.go using FakeSleeper. Cover success, exhausted attempts, cancellation, Permanent (errors.Is/errors.As) and the nil-sleeper path. For the default path, assert the owner's number as a literal in the test (with a comment citing the owner's answer), not the constant, for maxAttempts of 0 and of a negative value.

## Acceptance Criteria

- WHEN fn returns nil on some attempt THE SYSTEM SHALL stop retrying and have Do return nil. [FR-2]
- WHEN every attempt fails and the attempts run out THE SYSTEM SHALL return the last error from fn, having slept p.Delay(n) between attempts via the Sleeper (FakeSleeper.Delays holds one entry fewer than the number of attempts). [FR-2, FR-5]
- WHEN ctx is cancelled before or during a wait THE SYSTEM SHALL return ctx.Err(). [FR-2]
- WHEN fn returns Permanent(err) THE SYSTEM SHALL stop at once without further calls or sleeps and return an error for which errors.Is(result, err) is true. [FR-3]
- WHEN maxAttempts <= 0 and fn always fails THE SYSTEM SHALL call fn exactly N times, where N is the number the owner gave (asserted as a literal in the test), and record N-1 delays in FakeSleeper. [FR-4]
- Existing tests pass
- New functionality has test coverage
- Code follows repository conventions (see CLAUDE.md)

# T001: Backoff policy and sleeper

## In short

Adds the rule for how long to wait between retries (it grows each time, up to a ceiling) and a swappable 'waiter' so tests can run without actually pausing.

## Engineering plan
- **Repository:** `mayank-kochava/coding-agent-sandbox` (Go module `github.com/mayank-kochava/coding-agent-sandbox`, Go 1.22). Every task targets this repo.
- **Design:** `Policy` is a plain value type. `Do` loops, sleeps `p.Delay(n)` between attempts via `Sleeper.Sleep(ctx, d) error` (returns `ctx.Err()` if cancelled while waiting), and stops early on a `Permanent` error.
- **Stack:** Go standard library only. No new dependencies, no `go.mod` changes.
- **Testing:** table-driven tests with a fake sleeper that records delays; `go test -race ./...` passes, `go vet` clean.

## Implementation Guide

1. Create retry/policy.go in package retry (Go 1.22, standard library only, no go.mod changes).
2. Define `type Policy struct{ Base, Max time.Duration; Factor float64 }`.
3. Implement `func (p Policy) Delay(attempt int) time.Duration` returning Base*Factor^(attempt-1), capped at Max. Treat attempt < 1 as 1.
4. Define `type Sleeper interface{ Sleep(ctx context.Context, d time.Duration) error }` and `func RealSleeper() Sleeper`. The real sleeper waits for d but returns ctx.Err() if ctx is cancelled first.
5. Define `type FakeSleeper struct{ Delays []time.Duration }` with `func (f *FakeSleeper) Sleep(ctx context.Context, d time.Duration) error`. It appends d to Delays and never sleeps.
6. Write table-driven tests in retry/policy_test.go covering Delay (attempt 1, growth, cap, attempt < 1) and FakeSleeper recording.

## Acceptance Criteria

- WHEN Delay is called with attempt 1 THE SYSTEM SHALL return Base. [FR-1]
- WHEN Delay is called with attempt n > 1 THE SYSTEM SHALL return Base*Factor^(n-1), never more than Max. [FR-1]
- WHEN Delay is called with attempt < 1 THE SYSTEM SHALL treat it as attempt 1. [FR-1]
- WHEN FakeSleeper.Sleep is called with a duration THE SYSTEM SHALL append it to Delays, return nil and not actually wait. [FR-5]
- WHEN the context is cancelled while the real Sleeper is waiting THE SYSTEM SHALL return ctx.Err(). [FR-5]
- Existing tests pass
- New functionality has test coverage
- Code follows repository conventions (see CLAUDE.md)
